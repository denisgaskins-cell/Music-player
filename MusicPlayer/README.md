# Minimalist Android Music Player

Aplikasi Pemutar Musik Android ultra-minimalis berbasis Jetpack Compose, Media3 ExoPlayer, dan Material 3 (Monochrome Dark Theme).

## Fitur Utama
1. **Local Audio Scanner**: Membaca otomatis file .mp3 dari memori HP Android (MediaStore API).
2. **Search Bar**: Menyarikan daftar lagu berdasarkan judul dan artis secara real-time.
3. **Playback Controls**: Shuffle, Repeat (Off / All / One), Play/Pause, Next, Previous.
4. **Desain Minimalis**: Tema Pitch Black (`#000000`), fokus pada tipografi bersih dan hemat daya baterai OLED.

## Cara Menggunakan di Android Studio
1. Unzip file `Minimal_MusicPlayer_Android_Project.zip`.
2. Buka Android Studio -> Pilih **Open** -> Buka folder `MusicPlayer`.
3. Tunggu Gradle Sync selesai.
4. Klik **Run 'app'** atau **Build -> Build APK(s)** untuk membuat file `.apk`.
